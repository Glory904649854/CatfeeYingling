# 多语种翻译测评

测评目的：评估当前本地模型在「多语种 → 中文」以及「中文 → 英文」上的可用性，并明确哪些语种能端到端跑通。

## 1. 测评条件

- 翻译模型：Qwen2.5-0.5B-Instruct，Q4_K_M，llama.cpp
- 参数：greedy（temperature=0），最多 96 token，6 线程
- Prompt：`Translate ... Output only the translation.`
- 每种语言 3 句日常/课程风格短句
- 文本翻译测评在 PC 上跑同一模型（手机端延迟另计）

> 注意：这是**文本翻译能力**测评。App 当前的流式 ASR 只有中英双语模型，
> 日/韩/法/俄的语音识别尚未接入，因此这些语种暂不能端到端验证。

## 2. 测评结果

### 日 → 中：★★☆☆☆（最弱）

| 原文 | 译文 | 评价 |
|---|---|---|
| 今日はとても良い天気ですね。散歩でもしませんか。 | 今天天气真好啊。**我不去散步。** | ❌ 否定/邀约语气译反 |
| この映画は本当に美しい。もう一度見たいです。 | 这是一部**真的美**。还想看一次。 | ⚠️ 语句生硬 |
| 会議は三時に始まります。準備はできましたか。 | 会议将在三时开始。准备是否已完成。 | ✅ 可用 |

问题：日语省略主语、授受/否定语气多，0.5B 容易理解反；需要更大模型或日语专用 prompt。

### 英 → 中：★★★★☆（最好）

| 原文 | 译文 | 评价 |
|---|---|---|
| The database uses a three-level schema architecture. | 数据库采用三级模型架构。 | ✅ |
| Today we will discuss how on-device AI changes live translation. | 今天我们将讨论在设备上进行人工智能如何改变实时翻译。 | ✅ |
| Please submit your report before Friday. | 请在周五之前提交报告。 | ✅ |

### 韩 → 中：★★★☆☆

| 原文 | 译文 | 评价 |
|---|---|---|
| 오늘 회의는 세 시에 시작합니다. 준비되셨나요? | 今天会议从**上午九点**开始。您准备好了吗？ | ❌ 三点误译成九点 |
| 이 영화는 정말 아름다워서 다시 보고 싶어요. | 这部电影真的很美，我想再看一次。 | ✅ |
| 데이터베이스는 세 가지 수준의 구조로 나뉩니다. | 数据库分为三级结构。 | ✅ |

问题：数字/时间表达不稳定；整体可读。

## 3. 横向评分

| 方向 | 翻译质量 | 说明 |
|---|---|---|
| 英 → 中 | ★★★★☆ | 最稳，适合直接上线 |
| 法 → 中 | ★★★★☆ | 日常句很好，术语需词表 |
| 俄 → 中 | ★★★★☆ | 表现稳定 |
| 韩 → 中 | ★★★☆☆ | 数字/时间易错 |
| 日 → 中 | ★★☆☆☆ | 否定、省略、语气易翻错 |
| 中 → 英 | ★★★★☆ | 术语偶错（端侧→end-to-end） |

## 4. ASR 覆盖现状（关键）

当前流式 ASR 是 **sherpa-onnx zipformer 中英双语**模型：

| 源语言 | ASR | 端到端可行 |
|---|---|---|
| 中文 | ✅ sherpa 流式 zipformer | ✅ 中 → 英 已验证 |
| 英文 | ✅ SenseVoice | ✅ 英 → 中 已验证（6.4s 音频 → 译文 1.6s） |
| 日语 | ✅ SenseVoice | ✅ 日 → 中 已验证（6.1s 音频 → 译文 1.7s） |
| 韩语 | ✅ SenseVoice | ✅ 韩 → 中（同一引擎，未单独录音实测） |
| 法语 | ❌ | ❌ |
| 俄语 | ❌ | ❌ |

### 端到端实测样本

- 日 → 中：
  - ASR：`うちの中学は弁当制で持っていけない場合は50円の学校販売のパンを買う。`
  - 译文：`我家中学的食堂里，如果拿不到50円的学校售货的面包，就买学校售货的面包。`
  - 翻译耗时 1.7s；译文可用但略生硬。
- 英 → 中：
  - ASR：`The tribal chieftain called for the boy and presented him with 50 pieces of code.`
  - 译文：`部落酋长要求男孩并授予他50个代码。`
  - 翻译耗时 1.6s；语句通顺。
- 中 → 英：数据库课程实测，15~19 字 → 1.5~1.8s。

## 5. 补齐建议

1. **已落地：英/日/韩 → 中**
   - SenseVoice 识别 + Qwen 目标中文翻译
   - App 内把源语言选为英语/日语/韩语、目标选中文即可

2. **法/俄 → 中**
   - 接入 Whisper ONNX（sherpa OfflineRecognizer）
   - 覆盖全语种，但延迟会回到 10 秒级
   - 或者只做法/俄时用云端翻译/识别

3. **质量升级**
   - 日/韩：Qwen2.5-1.5B 或云端
   - 术语：维护领域词表（如“三级模式”“端侧”“物理模式”）
